## ⚠️ If Something Goes Wrong

### "LangChain components import failed"
```bash
# Fix: Reinstall packages
pip install --upgrade langchain langchain-mongodb langchain-google-genai
python app.py
```

### "Recommendation service not initialized"
1. Check Flask console for error messages
2. Verify MongoDB is running: `mongosh`
3. Verify Redis is running: `redis-cli ping` (should return `PONG`)
4. Verify `.env` has `GOOGLE_API_KEY` set

### "Still seeing old recommendations"
1. Clear PHP cache: Delete files in `backend/storage/cache/`
2. Hard refresh browser: `Ctrl+Shift+Delete` 
3. Verify PHP config changed (check `backend/app/config/config.php` line ~114)

## 📚 What Each Component Does

| Component | Role |
|-----------|------|
| **Hybrid Retriever** | Searches MongoDB for products (keyword + semantic) |
| **LLM Chain** | Generates natural language explanations using Gemini |
